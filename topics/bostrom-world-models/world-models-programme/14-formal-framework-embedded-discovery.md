# 14 — Formal framework: embedded discovery of generative structure; information-theoretic vs interface vs computational accessibility

Prior-art discipline: every statement is labelled **[known]** (standard; source named or background, access level stated in `13` §4), **[elementary]** (short proof, no novelty claimed) or **[test]** (a prediction checked in `15`). **No statement is claimed to be new.** Cryptographic/learning-theory sources were not read (NA); statements that rest on them are conditional on the named assumption.

## 1. Objects
* **Generative environment** E = (S, A, O, κ): hidden state space S, action set A, observation space O, kernel κ(s′, o | s, a). A **generator component** is a sub-process producing the environment's exogenous randomness: ξ_t = G(σ_t), σ_{t+1} = f(σ_t), with σ ∈ {0,1}^n (deterministic, n-bit state) or ξ iid (true randomness).
* **Embedded observer** O = (interface I, resources R, representation Z_θ, hypothesis language 𝓛, policy π). **Interface** I = (observation map, admissible action set A, reset capabilities ρ ∈ {none, replay-from-recorded-state, resample}). Resources R = (observations m, interventions, compute, memory/context k, model capacity).
* **Learned representation** Z_θ: a function of the observed history trained by prediction; **world model** W_θ: its predictive law.
* **Hypothesis language** 𝓛: the set of mechanisms the observer can *express and verify* (e.g. GF(2) linear recurrences; degree-≤2 polynomial recurrences). A **structural identification** is an element ĥ ∈ 𝓛 together with a *verification certificate* (§4); an **explanation** is such an ĥ that survives verification on fresh data; **epistemic justification** = the guarantee attached to the verification (type-I error bound under a declared null).
* Three nested notions of "can distinguish H_det(n) from H_rand": (a) **information-theoretic** (some test exists); (b) **interface-relative** (a test exists using only admissible actions/resets); (c) **resource-bounded** (a test exists within R, in particular within the observer's compute/memory).

## 2. Propositions
**P1 (information-theoretic detectability from a continuing stream) [elementary].** Let 𝒢 be a class of deterministic generators with n-bit state, |𝒢| = 2^c. A length-m output sequence under H_det has support of size ≤ 2^{n+c}, so any test accepting the support has advantage ≥ 1 − 2^{n+c−m} against iid fair bits. Hence with m > n+c an unbounded observer detects determinism with advantage → 1 (counting argument). *Prior art:* Kolmogorov/Martin-Löf-type randomness tests; textbook.

**P2 (replay test; interface asymmetry) [elementary].** If ρ = replay-from-recorded-state (the hidden seed can be restored and the same actions repeated), then for every deterministic generator of any structure the two shock sequences coincide with probability 1, whereas under iid fair bits they coincide on m bits with probability 2^{−m}. The test "reject H_rand iff sequences equal" has type-I error 2^{−m}, type-II error 0, and needs no knowledge of the generator's form, no computation beyond comparison, and no learning. If ρ = none, no test of this form exists; detection must proceed through prediction (P1/P3). *Prior art:* two-sample comparison/derandomisation folklore; I found no source stating it for embedded observers — originality unverified and unlikely.

**P3 (computational inaccessibility under an assumption) [known, conditional].** Assume a pseudorandom generator exists: seed length n, output length m(n) = poly(n), outputs computationally indistinguishable from iid bits by every polynomial-time test. Then for the continuing interface every polynomial-time observer — including any learned world model of polynomial size trained with polynomially many samples — has negligible advantage, although P1 gives advantage ≥ 1 − 2^{n−m} ≈ 1 to an unbounded observer, and P2 gives advantage 1 with two episodes if replay is available. Equivalence of next-bit unpredictability and indistinguishability (Yao; Blum–Micali; attribution to Yao 1982 questioned in Reyzin's notes) means the same holds for *prediction*: no polynomial-time predictor achieves click cross-entropy below ln 2 by more than a negligible amount. *Status: assumption-based, SD-level source only.*

**P4 (accessibility depends on the declared class) [known].** For a Fibonacci LFSR with n-bit state, Berlekamp–Massey identifies the recurrence exactly from 2n output bits (unit-tested here). For a nonlinear-feedback register of degree 2 the linear complexity of the output is generally ≫ n, so BM (class: linear recurrences) does not yield a short explanation, while a degree-≤2 GF(2) polynomial fit over the last L ≥ n bits does with O(L²) equations (unit-tested). The *same* data are "easy" or "intractable" depending on 𝓛 — the generator analogue of the hypothesis-class lessons of `12`.

**P5 (window property: provable memory threshold for finite-context predictors) [known fact, elementary consequence; test].** In a maximal-length LFSR sequence (m-sequence) with n-bit state and uniformly random nonzero seed, every nonzero k-bit window (k ≤ n) occurs equally often (2^{n−k} times in a period) and the all-zero k-window 2^{n−k} − 1 times (Golomb's balance/window property; background). Hence for any predictor whose input is only the previous k < n output bits, the conditional law of the next bit given that window is within O(2^{−(n−k)}) of fair, so its expected cross-entropy is ≥ ln 2 − O(2^{−(n−k)}): **with context shorter than n bits the detectable advantage is exponentially small in n−k, however good the optimiser (measured: exact Bayes CE over a full period is ln 2 − 0.011 at n=6,k=5; −0.0027 at n=8,k=7; −0.0006 at n=10,k=9; ≈ −10⁻⁴ at n=12,k=11), while at k ≥ n it is exactly 0.** A world model whose latent state cannot retain n bits of click history (finite context, Markov truncation, small recurrent state) therefore *cannot* discover an n-bit LFSR from a continuing stream even though the property is information-theoretically identifiable. This is the cleanest *representation-induced epistemic limitation* in the framework. [test: window-MLP controls, `15`].

**P6 (null-valid agent-computable detection) [elementary].** Let q_t be any predictor of the click b_t measurable w.r.t. the past (a frozen learned world model). Under H_rand, X_t = −log q_t(b_t) has E[X_t | F_{t−1}] = ln 2 + KL(½ ‖ q_t) ≥ ln 2. With q_t clipped to [ε, 1−ε], X_t is bounded by log(1/ε), so for the mean over m clicks of an independent stream Azuma–Hoeffding gives P_rand( X̄ ≤ ln 2 − δ ) ≤ exp(−2 m δ² / log²(1/ε)). Streams are independent, so a one-sided t-test on per-stream means (used in `15`) is asymptotically valid; the clipped Hoeffding bound is non-asymptotic. The predictor may be arbitrarily wrong or overconfident under H_rand — it can only lose. (Unit-tested with an overconfident predictor.) *Prior art:* properness of log-loss; test martingales/e-values (NA).

**P7 (verification certificate for an extracted mechanism) [elementary].** If ĥ ∈ 𝓛 predicts m fresh click bits exactly, then under H_rand this has probability 2^{−m}; the multiple-hypothesis cost of selecting ĥ from the model's behaviour is irrelevant because verification uses fresh independent data. Thus a *discovered mechanism* carries an exact error guarantee 2^{−m} against "iid fair coin" — but says nothing about alternatives outside {H_rand} (e.g. a different deterministic generator that happens to agree on m bits is ruled out only by more data), and nothing about whether the recurrence is the *implementation*: only that it is observationally sufficient (level 3–4 in the earlier hierarchy).

**P8 (nested worlds reduce to hidden-state augmentation) [elementary].** A world containing an agent that itself learns a world model, observed only through an interface, is a controlled process with hidden state (outer ⊗ inner learner state); its observation kernel is a single κ, and interventional equivalence is decided by κ alone. A nested world and a flat world with the same κ are exactly equivalent (P1 of `08`). The only new quantity is *resource propagation* (the outer budget bounds inner resolution/steps), which enters as a constraint on 𝒢, not as a new identifiability phenomenon. Hence Programme C is not pursued as a separate research programme; its resource-propagation corollary is folded into P3/P5.

## 3. Epistemic ladder for this study (and why each step needs extra assumptions)
1. *Anomaly*: click CE < ln 2 on fresh data (P6; valid test, no mechanism).
2. *Predictive model rejected/refined*: the iid-shock model is rejected (same test).
3. *Mechanism identified*: ĥ ∈ 𝓛 verified (P7), class-relative.
4. *Computational implementation*: only that a short deterministic recurrence reproduces the event stream; says nothing about hardware, substrate or whether an equivalent non-computational physical law is responsible (e.g. deterministic chaos with a finite-dimensional attractor yields the same prediction).
5. *Environment is simulated*, 6. *ancestor simulation*: require premises about who runs which generator and why; **no experiment in this study bears on them.** Bostrom's trilemma concerns the distribution of observers; a perfect simulation with true randomness would defeat levels 4–5 detection entirely.

## 4. What the framework predicts (checked in `15`)
(i) learned detection frontier moves with state size n, context/capacity and data; (ii) a finite-context learner has a *hard* threshold at k = n (P5); (iii) detection by a learned model is null-valid (P6) and cross-environment z is non-positive; (iv) extraction + verification succeeds only where the learned predictor is exact and the language contains the generator (P4, P7); (v) replay detects every generator regardless of n or class (P2) while prediction does not.
