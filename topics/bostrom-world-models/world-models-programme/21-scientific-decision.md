# 21 — Scientific decision: from failed world models to structural discovery

Evidence: `18` (literature), `19` (framework, protocol, addenda), `20` (experiments). Development evidence only; internal analysis, not peer review; no confirmatory run was made and none is authorised.

## 1. Verification of the previous negative findings (from artifacts, before new work)
Checked against `17`, `results/mdw_dev/` and the unchanged code (suite re-run: 350 passed before any change). Not all failures share a cause:

| finding | verified | diagnosis |
|---|---|---|
| direct probing ≫ world model on held-out constructions | yes (`17` §1: 0.09/0.16 vs 2.6/1.3 at B=4) | **evaluation-design bias** (descriptors defined by the very probe programmes direct probing runs) plus **predictive-model failure** (negative transfer) |
| learned planner worse than fixed sweeps | yes | **experiment-selection failure** *given* a poor model: ensemble disagreement of a poorly generalising ensemble points at ensemble artefacts |
| more training did not fix negative transfer | yes (v2 12 000 steps) | **predictive-model failure** (imagination), not under-training at this scale |
| supervised head on the same encoder strong in-family (0.09) | yes | **not a representation failure**: the context state carries the information; the autoregressive imagination route loses it |
| imagined intervention outcomes unreliable | yes (`wm_imagination_diagnostic.txt`) | predictive-model failure |
| declared-class goodness-of-fit beats ensemble spread for detecting held-out mechanisms | yes, AUROC 0.80–1.00 vs unreliable | misfit tests need a *structured* null, not a heuristic score |
| descriptors aligned with the direct-probing baseline | yes (documented in `17` §5) | **evaluation-design bias**; motivated the present environment, in which the target is an executable mechanism scored on fresh interventions |
Structural-hypothesis failure — the generator family was outside the declared class — is the one cause the MDW experiment could not test (the agents chose descriptors, not mechanisms); the present study tests it.

## 2. Answer to the mission question, with limits
*Can an agent detect that its structural class is inadequate, construct a previously unavailable structural explanation and design experiments that distinguish it from rivals?* **Partly, in a generator-aligned grammar:**
* **Construct the explanation:** yes — a forward search over an expressive primitive grammar recovered the function of unfamiliar in-language mechanisms in 0.95 (B=8, 95 % CI 0.91–0.98) of instances against 0.25 for the declared class, ≤ 0.44 for the best generic baseline (Hammerstein), ≤ 0.21 for SINDYc (even with an oracle hidden state), 0.11 for ridge NARX. **But the grammar's primitives are the simulator's vocabulary**, so this shows that *having the right primitives* and a tractable search suffices with 5–8 interventional episodes; it does not show open-ended hypothesis generation. PySR, weak-/implicit-SINDy were not run.
* **Detect inadequacy:** the residual statistic ranks out-of-language instances well (AUROC 0.98 at B=8), but the pre-specified plug-in χ² rule over-rejected valid claims (0.15–0.62) and the pre-stated H3 **failed**; an empirical null estimated on valid known-family fits, applied to a fresh namespace, brought false rejection to 0.03 with osc claim rate 0.10 — a calibration artefact, fixed — yet the net benefit over simply always claiming is **not demonstrated** (+0.03 [−0.02,+0.08] decision accuracy) and negative with the weaker design. Also, osc is *predictively* well approximated (0.78 recovery), so "abstain" is correct only under a strict structural standard.
* **Design the distinguishing experiment:** design did **not** raise predictive recovery over a good fixed sweep or random programmes (H2 failed); it beat a generic ensemble-variance design clearly and matched declared-class EIG. One exploratory effect replicated across two development sets: designed experiments cut residual structural ambiguity at B=8 from 0.28/0.21 to 0.10/0.07, raising calibrated decision accuracy by about 0.10 (B=5, 8) — a modest, unconfirmed effect on *resolution of rival structures*, not on prediction.
* **Do learned world models help?** *Role A (neural imagination as predictor and planner):* no (`17`; not re-run). *Role B (learned latent state):* a bidirectional-GRU estimator trained only on known families matched the privileged oracle state and beat a naive derivative reconstruction for proposing the right primitive (+0.13 [0.09,0.17]); a tuned model-based smoother was not tested (an untuned one was worse), and for SINDYc the learned state equals the oracle state but neither lifts SINDYc above 0.39, so the representation is not the bottleneck there. **The mission's central claim — learned latent + structure search + falsification design beats symbolic/system-identification methods alone — is not established**: structure search carries the effect; the latent estimator is *sufficient but not shown necessary*; design shows only the ambiguity effect.

## 3. Mathematics: status
* **S1** (interface-limited exact equivalence; a threshold above the actuator reach is interventionally identical to no coupling) — elementary, tested exactly, and operationally relevant: the agent claimed the correct (null-equivalent) explanation in 0.80–1.00 of unreach instances at B ≥ 5 (uncalibrated full rule: 0.80 at B=5, 0.90 at B=8; calibrated rule: 1.00).
* **S2** (pairwise-disagreement elimination removes ≥ 1 wrong hypothesis per noiseless experiment, ≤ |𝓗|−1 experiments; the survivor is *not certified* if truth ∉ 𝓗) — elementary; it predicts what was seen: ambiguity falls with designed experiments, while class inadequacy needs a separate misfit statistic. **S3** (Le Cam two-point noisy distinguishability) — known; used as the design score. **S4** (EIG pathology under misspecification, Rainforth et al. §5.3) — known; the declared-class baselines failed out of class exactly as it predicts (0.25 vs 0.95) and the declared-class Bayes goodness-of-fit flag did not fire for osc (AUROC ≈ 0.5), so a class-internal posterior cannot be trusted to flag class inadequacy. **S5** (learned estimator should not beat analytic reconstruction because inversion is mechanism-independent) — half wrong: transfer to unfamiliar mechanisms held as predicted, but a learned advantage appeared against the weak analytic comparator.
* No new theorem is claimed; no counterexample beyond the above was found. The sufficiency question left open — which sequences of admissible interventions falsify *every* hypothesis of a misspecified class — reduces to S2's corollary and needs a challenger class; it is not resolved here.

## 4. Relationship to Bostrom (philosophical, kept apart from the results)
For an embedded observer: **passive observation** carried no structural information here (zero-input responses are identical across all families, tested); **interventions** carried all of it, and different mechanisms needed different interventions (u2 injection for hidden feedback, sign reversal for thresholds, cycling for memory, timing for delay). **Rejecting a wrong generative hypothesis** is possible but needs a *calibrated* misfit test; an uncalibrated one rejected 15–60 % of correct explanations — a warning for any argument that proceeds from "this model fails" to "reality has hidden structure". **Discovering a new structure** worked only because the language already contained the right primitives. **Observational equivalence** is real and sharp (S1) and also soft: several structurally different hypotheses predicted the tested interventions equally well (term identity 0.2–0.4 for hidden feedback despite recovered function; osc approximated within tolerance), so "recovered the mechanism" and "recovered an interventionally adequate mechanism" must not be conflated. **Computational and experimental constraints:** 5–8 episodes sufficed with a tailored grammar, but the toy observer could reset the world, choose arbitrary programmes and replay episodes; observers in our universe cannot. None of this bears on whether we are simulated: detecting deterministic or compositional structure does not establish a simulation, and nothing here changes any probability.

## 5. Decision
* **Hypotheses:** H1 supported (aligned grammar vs configured baselines); H2 not supported for recovery; H3 failed as pre-stated, repaired by calibration with no demonstrated net benefit; H4 supported against a weak comparator, interpretation open; H5 not supported.
* **Programme: REVISE (not NO-GO, not GO).** A narrower question is justified; a confirmatory study is **not** (no result is both pre-specified-positive and unexplained by prior art). The previous NO-GO for *learned imagination as the discovery engine* stands.
* **Strongest remaining claim, if any, would be:** *calibrated misfit-triggered structure search with ambiguity-reducing experiment design reaches interventionally adequate explanations of unfamiliar mechanisms from a few episodes, and abstains on out-of-language mechanisms at an empirically calibrated rate.* Each ingredient is covered by prior art (`18`); only the composition and its evaluation are unread-literature gaps, and the grammar-alignment caveat blocks any generality claim.

## 6. Next decisive milestone (evidence-gated; development only)
1. **Break the alignment:** rebuild the held-out families from primitives not in the grammar's vocabulary (rate limiters, asymmetric/rectified saturation, composite delays, state-dependent time constants) and report recovery with the same loop — if it collapses, the study reduces to structure selection; if it holds through grammar *growth* (e.g. compositional extension triggered by calibrated misfit), the open-ended question becomes testable.
2. **Strong baselines first:** install Julia and run PySR; run weak- and implicit-SINDy and a tuned Kalman/EKF smoother as the analytic state estimator; re-test H1 and H4 against them before any new component.
3. **Ensemble-variance design with a good structured model** (bagged grammar fits, E-SINDy style) instead of the NARX ensemble, and a replication of the ambiguity effect on a fresh namespace.
4. A confirmatory design only if (1)–(3) leave a result not predicted by prior art; namespaces ≥ 30 000; reserved seed ranges untouched.
