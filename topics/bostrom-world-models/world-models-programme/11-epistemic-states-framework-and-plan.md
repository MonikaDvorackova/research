## 2. Formal framework
G: family of mechanisms; g ∈ G true; A: admissible action space (here [−1,1] per step, horizon L=48 per episode; adaptive policies π allowed); P_g^π: law of the observation history under π.
* **Interventional equivalence** g₁ ~_A g₂ ⇔ P_{g₁}^π = P_{g₂}^π ∀π∈Π_A. Variants: ~_{A,L} (horizon L, **finite-horizon**), ~_{A,B} (budget-limited: policies using ≤ B interventions of cost ≤ c), ~_{A,ε} (**approximate**: sup_π TV(P_{g₁}^π,P_{g₂}^π) ≤ ε, or sup_π KL ≤ ε), **model-relative** (equivalence among g ∈ H only), **observer-relative** (laws of the observer's feature process), **policy-restricted** (π∈Π′⊂Π_A).
* **Epistemic states** for (g, H, history h_t, remaining budget B_t):
  A: identifiable now — posterior over the equivalence classes of H concentrates (max class posterior ≥ 1−α) under the assumed H.
  B: identifiable after experiment — A fails now, but ∃π with remaining budget B_t whose expected posterior concentrates.
  C: non-identifiable — ∃g′≠g in H with g′ ~_A g (exact), certified by proof or structural argument.
  D: unknown — g ∉ H (or H not known to contain g).
  (Two further regimes are reported as sub-cases, not states: **budget-limited** — identifiable in principle (B for larger B) but not within B_t; **approximately equivalent** — g′ ~_{A,ε} g with ε small but >0.)
* The states are **not** a supervised 4-way labelling: A/B depend on history and budget; C is a property of the pair (g,H,A); D is a property of (g,H) that no function of finite data inside H can certify (Prop. E3).
* Five non-interchangeable statements: (S1) no experiment can distinguish [state C]; (S2) no affordable experiment can [budget-limited]; (S3) the planner has not found one [planner-relative]; (S4) the representation cannot express the distinction [representation-relative]; (S5) H lacks the true mechanism [state D]. A procedure may output S3/S2-type abstentions from data; S1 requires a certificate (proof, structural argument, exact equivalence of the declared parametric forms); S5 is never certifiable from within H.
* **Agent** actions: Identify (report class), Experiment (choose intervention), Abstain with reason ∈ {temporary (more experiments judged useful), persistent-uncertified (judged unhelpful by the agent's own models), certified-C (only if an exact structural certificate exists), out-of-class-suspected}. Objective: expected utility U = +1 correct identify, −λ wrong identify, 0 abstain, −c per intervention block; with λ chosen so that a Bayes-optimal agent identifies iff posterior ≥ λ/(1+λ).

## 3. Statements (all elementary or known; no novelty claimed)
* **E1 (Le Cam two-point; known, NA).** If g₁ ~_{A} g₂, any (adaptive, randomised) procedure has Bayes risk ≥ ½(1−TV)=½ for the pair; a calibrated claim cannot exceed the prior-implied ½ (proved in `08` P1 by induction on the sequential kernel).
* **E2 (finite-sample non-testability of exact equivalence; known flavour, NA).** Let Θ be a continuum of alternatives with g_θ → g₀ as θ→0 (e.g. quantisation step q ↑ actuator reach). For any finite budget B and any procedure that, under g₀, outputs "equivalent" w.p. ≥ 1−α, there are θ>0 with g_θ not ~ g₀ under which it outputs "equivalent" w.p. ≥ 1−α−TV(P_{g₀}^{π,B},P_{g_θ}^{π,B}) → 1−α as θ→0. Hence a finite data/budget decision rule cannot **certify** exact equivalence in a nonparametric neighbourhood; it can certify only (i) ε-approximate indistinguishability at budget B (a testing bound), or (ii) exact equivalence **within a declared parametric family** by a proof about that family. (Bahadur–Savage / Donoho-type; precise citation NA.)
* **E3 (D is not certifiable inside H; elementary).** For any decision rule based on likelihoods within H, there is g ∉ H whose observation law, restricted to the realised histories under the agent's policy, equals that of some h ∈ H; so high in-class posterior cannot establish g ∈ H. Out-of-class **detection** is possible only against explicit alternatives (goodness-of-fit with power against specified departures).
* **E4 (learnable only under assumptions).** A learned procedure that abstains on unseen equivalence sources must rely on an inductive bias linking behaviour to structure (e.g. a learned simulator that extrapolates correctly to the unseen mechanism). Absent such a link, ambiguity exposure on sources S₁…S_k cannot constrain behaviour on S_{k+1} (no-free-lunch for the epistemic task; formalised only as the E2/E3 arguments).

## 5. Benchmark extension (module `eid.gwb.epi`)
Categories (ground truth by construction + exact computation; labels are privileged, agent sees only (a,y)):
* **id** identifiable (train regime; gwb families A,B); **idnoisy** budget-limited (σ ×3: same mechanisms, hard within budget).
* **Exact equivalence sources** (qualitatively different): eqA actuator-reach (quant≡stiff, threshold beyond reach); eqB horizon (delay ≥ horizon ≡ reset period 1); **eqC timescale-below-sampling** (lag τ=0.05<dt ≡ delay 0; x identical); **eqD null actuation** (b=0: all classes of a family identical). Unit tests verify exact identity of observation laws.
* **approx** approximate equivalence (quant/stiff thresholds at 60–95 % of actuator reach: distinguishable only by near-saturating actions; exact divergence reported via oracle).
* **ooc** out-of-class mechanisms: saturating actuator, underdamped second-order dynamics, quantised+delayed composite.
* Family II (identifiable only after intervention) is realised by the protocol: every adaptive agent starts with a passive weak block (a_t~N(0,0.3²)); a zero-action start makes all classes equivalent (tested), so interventions are required.
* Family VII (nested worlds) **not implemented**: I could not specify a nested design whose detectability is not trivial or ill-posed; omission recorded.
Leakage audit: all categories share L=48, same action range, same noise-stream construction (shared ε draw), same σ ranges per family, no resets visible except as physical dynamics; audit test trains a gradient-boosting classifier on nuisance statistics (noise level, initial-block mean/var) to predict category and requires accuracy near the majority-class baseline within a family.

## 6. Methods compared (all see the same 48-step budget; adaptive ones start from the passive block)
M1 exact-Bayes oracle (declared structure; knows families, K, b, σ; broad grid incl. degenerate members) — structural reference with model-relative certificates; M1s oracle on fixed sweep. M2 probe softmax (frozen prediction-trained GRU latent; trained on identifiable only). M3 probe + temperature scaling. M4 split-conformal singleton rule. M5 ambiguity-exposure probe (eqA, eqB labelled ambiguous; tested on unseen eqC, eqD). M6 3-seed ensemble probe. **M7 intervention-aware learned simulators**: a class-conditional GRU world model (trained only on identifiable data, labels = class) provides per-class sequence likelihoods (→ posterior) and imagined responses to candidate interventions; the agent experiments with the programme maximising posterior-weighted pairwise predicted divergence, claims if posterior ≥ τ, and flags *persistent-uncertified* abstention if the learned simulators of the top-2 classes predict (almost) identical responses for every candidate (d_max < δ=4 ≈ squared 2σ). M7s = same model on the fixed sweep (isolates adaptivity).
Hypothesis class for M1/M7 = the six classes; ambiguity exposure only in M5.

## 7. Pre-stated analysis rules
* Operating point: each method's claim threshold is set on a **calibration set of identifiable instances (ns 11110)** to give 70 % claim coverage; then applied unchanged to all test categories. Primary metric: **claim rate on unseen exact-equivalence sources (eqC, eqD)** at this operating point (lower is better, oracle ≈ 0), with Wilson 95 % intervals over instances; also wrong-claim rate on id/idnoisy, claim rate on ooc, AUROC of the claim score for {id-correct} vs {eq, ooc}.
* H1 supported if M2/M3/M4/M6 claim rate on eqC/eqD ≥ 0.3. H2 supported if M5 is lower than M2 on seen sources (eqA/eqB) but not meaningfully lower (difference < 0.1) on unseen. H3 supported if M7 < M2 on eqC/eqD by ≥ 0.15 absolute with non-overlapping CIs **and** its persistent-uncertified flag is raised on ≥ 0.6 of abstentions on eqC/eqD but ≤ 0.2 on idnoisy abstentions. H4: oracle vs best learned. H5: E2/E3 argument only; tested via approx family (certificate vs ε).
* Reasons reported separately from decisions; abstaining for the wrong reason (low posterior because of poor fit, not because of recognised ambiguity) is tracked via the persistent flag and the goodness-of-fit flag.
* Development only; ≤ 3 world-model seeds; 3 conditional-simulator seeds; no confirmatory claims.
