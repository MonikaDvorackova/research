# Embedded-observer formal model

Status: mathematical working document. Proof status labels: **P** proved here (complete proof given), **K** known (source given), **E** elementary consequence of definitions, **C** conjecture, **O** computational observation (exact finite computation, not a proof). ## 1. Host, observer, factorization
**Host.** A finite stochastic dynamical system H = (S, T, μ₀): S finite, T(s′|s) a Markov kernel, μ₀ a law on S. Time is discrete; a *trajectory* is (s₀, s₁, …).
**Factorization.** A *factorization* is a bijection S ≅ S_E × S_O. It is **not** assumed unique or privileged (Section 5). Given one, s = (e, o), with e the "environment" component and o the "observer" component.
**Observer interface.** Three maps fixed with the factorization:
* *actuator* α : S_O → A (finite action set), the intended action read off the observer's state;
* *sensor* ω : S_E → Y (finite observation set): what the observer can sense about the environment component;
* *record* r : S → R, the observer's internally accessible information. In the basic model r(s) = o (the observer's entire internal state: memory is the only thing the observer "has").
The **observer-visible history** at time n is the sequence (o₀, o₁, …, o_n) (equivalently, the observations and actions as seen from inside); the **full host trajectory** (e₀,o₀,…) is not accessible. Identification statements are made about *functionals of H* from the law of the observer-visible process under μ₀ and T.
**Resources (accounting).** (i) memory: m = |S_O|, i.e. log₂ m bits; (ii) time: one host step per observer step (observer computation is a part of the host dynamics); (iii) interventions: only those realised by α through T; (iv) no external reset, rewind, privileged access to e, or free randomness: the observer's randomness is whatever the kernel T supplies.

## 2. Sequentially factored hosts (SF) — the "no shared noise" regime
Say H is **sequentially factored** with respect to the factorization and interface if
**(SF1)** T((e′,o′)|(e,o)) = K(e′ | e, α(o)) · κ(o′ | o, ω(e′)) for kernels K : S_E × A → Δ(S_E), κ : S_O × Y → Δ(S_O);
**(SF2)** μ₀ = μ_E ⊗ μ_O (initial independence).
(SF1) says: the environment updates using only its state and the observer's *current* intended action; the observer then updates using only its own state and its fresh observation; the two updates use *independent noise*.

**Theorem 1 (embedding reduction; P).** If H is SF then the observer-visible process has the same law as the process generated by the POMDP 𝓜 = (S_E, A, Y, K, ω, μ_E) controlled by the finite-state controller 𝒞 = (S_O, α, κ, μ_O) with memory size m = |S_O|. Conversely, every pair (finite POMDP with deterministic observation function, finite-state controller with deterministic action readout) arises from an SF host.
*Proof.* Write the host's trajectory probability: P(e₀,o₀,…,e_n,o_n) = μ_E(e₀)μ_O(o₀) Π_{t=1}^{n} K(e_t|e_{t−1},α(o_{t−1}))·κ(o_t|o_{t−1},ω(e_t)) by (SF1)–(SF2) and the Markov property. The POMDP–FSC pair generates exactly this: the environment draws e_t from K given (e_{t−1}, a_{t−1}=α(o_{t−1})), emits y_t = ω(e_t), and the controller moves to o_t ~ κ(·|o_{t−1}, y_t). Hence the joint laws of (e_t, o_t)_{t≤n} coincide for all n, hence so do all functions of them, in particular the observer-visible history. The converse is the same factorisation read backwards. ∎ (Elementary; the formal identification "embedded observer = finite-state controller (FSC) of a POMDP" is standard in POMDP planning — see the prior-art file.)
**Consequence.** For SF hosts, *every* identifiability, learnability or lower-bound statement for embedded observers is a statement about POMDPs under the policy class Π_m of m-state time-homogeneous controllers. The embedding constraint is then exactly: finite memory m; time-homogeneity (the kernel κ does not depend on t; no external clock); the controller's randomness lives in κ (Theorem 1 uses the independence in (SF1)). **Whether finite-memory policy classes change identifiability is classical** (Section 6, Hellman–Cover).
**Examples.** (a) A thermostat in a room: S_O = {on, off}, ω = temperature reading. (b) A reader of a clock: S_E ⊃ phase, ω hides phase.
**Exact check (O).** Random SF hosts (|S_E| ≤ 4, m ≤ 3, words up to length 5): the observation-word law computed by forward recursion on the joint host chain and by an independent POMDP belief filter agree to 3.3×10⁻¹⁶ (`scripts/embedded_reduction_check.py`, `results/embedded/reduction_check.json`). This checks the implementation, not the theorem.

## 3. When the reduction fails: shared noise (non-SF hosts)
(SF1) can fail: the kernel T may couple the noise that drives the observer's next state or its *realised* action with the noise driving the environment (common causes in a single physical system). Then the observer's *intended* action z = α(o) and the *realised* effect on the environment are linked by hidden variables. Two standard readings:
* **Confounded POMDP.** The observer's record process is the law of a POMDP whose policy depends on hidden state (so it is not an experiment in the do-sense).
* **Instrument.** If the shared noise acts on the realised action a = g(z, U), the observer's controllable variable z is an *instrument* for a (noncompliance), not a do-intervention on a.
**Theorem 2 (non-reduction; P, elementary; = Pearl's layer separation).** There exist two hosts H₀, H₁ and one observer program (same α, ω, κ, same S_O) with identical observer-visible laws for all n and different interventional laws.
*Proof (explicit).* Hidden bit U ~ Bernoulli(½) is shared by the actuator and the environment. The observer chooses an intent z uniformly (from its own coin). The realised action is a = z ⊕ U. The environment returns Y = a ⊕ s, where s ∈ {0,1} is the host type (H_s). Under both types (z, Y) is uniform on {0,1}² (Y = z ⊕ U ⊕ s, U uniform and independent of z), so the observer's record law is the same for s = 0, 1 at every horizon (the transcripts are iid uniform pairs). But the do-laws differ: do(a): Y = a ⊕ s is deterministic and differs between s = 0 and 1. ∎ Verified exactly in `embedded_reduction_check.py`.
**Consequence (K).** In non-SF hosts, interventional functionals are not identified from the record process without further structure (proxies/instruments); this is exactly the content of the Causal Hierarchy Theorem (Bareinboim et al., R-60, Thm 1) and of instrumental-variable analysis (Balke–Pearl; Imbens–Angrist — not accessed). Bell-type relaxations of "measurement independence" quantify how much dependence suffices to hide a difference: Barrett–Gisin (2011) show all singlet correlations reproducible with mutual information ≤ 1 bit between a setting and the hidden variable. **No embedding-specific new theorem here.**

## 4. Latency and real-time embedding
If observer computation takes d host steps, the action at time t can depend only on observations up to t−d. **Proposition 3 (E).** An SF host with computation latency d is a POMDP–FSC pair with an action buffer of length d added to S_E (the standard reduction of delayed MDPs to MDPs). No change in the class of identifiable behaviours except the policy class.

## 5. Non-uniqueness of the factorization
A host admits many factorizations S ≅ S_E × S_O; the factorization determines which part is called "environment". **Proposition 4 (E).** The observer-visible law depends only on (T, μ₀, r, ω, α), not on any labeling of S_E; two hosts related by a bijection of S_E that preserves K, ω, μ_E have identical record laws, and so do two hosts whose environment components are *bisimilar* (lumpable onto a common quotient). Therefore any identification target that is not invariant under such relabelings/lumping (the number of environment states, the identity of hidden states) is unidentifiable *by construction*; admissible targets are properties of the **minimal realisation of the observer-visible process** (for controlled systems: of the system-dynamics function; Singh–James–Rudary 2004 for the linear case). In the embedded case the process is generated under one fixed controller, so the identifiable object is a single stochastic process law (plus whatever interventions the controller's own exploration produces), not a controlled system with free inputs; minimal realisations of a single process (the HMM realisation problem) are the relevant canonical object and are *not* unique/closed-form in general (Vidyasagar's survey — not accessed).
Examples: the one-state host emitting i.i.d. fair bits vs the two-state host with a freshly resampled hidden bit emitted each step have identical observation laws (technical note, §3).

## 6. What embedding changes, precisely
After Theorems 1–2 and Propositions 3–4, **embedding adds exactly three things beyond the external-controller POMDP interface**:
1. **Finite, time-homogeneous memory** (S_O of size m, κ independent of t). This is a genuine restriction on the policy class and is **not** equivalent to "restricted reach". Known theory: with m states and a time-invariant (stationary) automaton, simple-vs-simple testing between i.i.d. hypotheses with likelihood-ratio bound λ has irreducible asymptotic error ≥ 1/(1+λ^{m−1}) in the optimal case, whereas time-varying (clocked) or unbounded-memory observers reach error 0 (Cover 1969; Hellman–Cover 1970, as restated in the primary text of B. T. K. Leung, "Learning in a Small/Big World", arXiv:2009.11917; original not accessed). **K.** Consequence for embedded identification in the limit: *an embedded finite-state observer cannot identify, with vanishing error, a noisy mechanism that an unbounded-memory external observer identifies.* The error floor is explicit.
2. **Possible shared noise** (violations of SF1). Consequence: interventional identification = confounded-POMDP/instrument identification (K).
3. **No privileged factorization**: targets must be invariant (Prop. 4, E).
Two further features are *not* new restrictions: unreachable parts (policy-class restriction: E) and observer–host resource coupling (the host's resources bound the observer's; for cryptographic indistinguishability this changes nothing beyond a polynomial overhead — see the log, entry E10).

## 7. Identification notions used
* **Interventional equivalence** of two hosts H, H′ relative to an observer program π: equality of the laws of the record process of π. **Observational/predictive** equivalence: equality for the passive program(s). These are the interface-relative equivalences of `identifiability-and-embedded-observers.md`, with Π_I replaced by {the controller's own policy} or Π_m.
* **Structural identifiability** of a parametrisation, **statistical** identifiability (finite data; Le Cam two-point bounds), **computational** identifiability (bounded distinguishers) as in that file; unchanged.
* **Self-knowledge barrier (E).** The observer's own transition rule κ restricted to unvisited (memory, observation) pairs is part of H but not of the record process: a finite-state observer cannot identify what it would have done at situations its own trajectory never visits, and it cannot store a description of its full own table (|table| > log m bits) — a finite-state, elementary instance of the self-inference limits in Wolpert (2008) (see prior-art file; Wolpert's results hold for inference devices defined via arbitrary setup functions, a stronger-assumption setting).
