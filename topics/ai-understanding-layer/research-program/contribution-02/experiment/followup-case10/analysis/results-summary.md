## Headline pattern

**F10-1 (control): B and C identical, both fully correct.** Confirms
this follow-up did not generally cripple Regime B — its ordinary,
non-ambiguous reconstruction ability is untouched, exactly mirroring the
primary experiment's own control-case result.

**F10-2, F10-3, F10-5 (policy/authority/combined ambiguity, no causal
signal): C strictly dominates B, and B fails honestly, not falsely.**
Regime B never produces `WRONG_UNIQUE` on any ambiguous dependency in
this run (**False Historical Confidence = 0.00 on every single case**,
including every ambiguous one) — it correctly reports `AMBIGUOUS` with
Ambiguity Detection Rate = 1.00 wherever the ground truth says a
dimension is genuinely underdetermined by the observable record. Regime
C resolves every one of these cases to `CORRECT_UNIQUE` via its binding.
Authorization Correctness is 0 for B on all of these (it correctly
refuses to guess Q7 through an unresolved dependency) and 1 for C.

**F10-4 (model ambiguity): the same honest-ambiguity pattern appears on a
dimension Temporal Correctness does not score.** B's model resolution is
`AMBIGUOUS` (ADR = 1.00, FHC = 0.00), but TC = 1 anyway, because Temporal
Correctness is scoped to policy+authority only (matching the primary
experiment's scope exactly, `PRE-EXECUTION-MANIFEST.md`). Unique
Reconstruction Rate (0.67, not 1.00) is what actually captures this
case's effect — a direct, expected illustration of why TC alone is not
sufficient to characterize every dependency's behavior, and why URR was
included as a separate metric.

**F10-6 (negative control): B, given one non-binding causal consumption
event, exactly matches C.** Identical case structure to F10-2, except
Regime B additionally receives `{"policy_version_id": "v2"}` as an
ordinary trace field, never framed, named, or structured as a
`DecisionBindingRecord`. Result: B's policy resolution becomes
`CORRECT_UNIQUE` (ADR drops to 0.00 because there is no longer any
ambiguity to detect), TC = 1, AC = 1, FHC = 0.00 — identical to C on
every metric.
