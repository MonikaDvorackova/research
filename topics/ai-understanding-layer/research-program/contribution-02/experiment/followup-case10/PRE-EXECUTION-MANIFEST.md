## Locked reconstruction algorithm

`src/reconstruction.py::reconstruct`. Per dependency (policy, authority,
model), a bucket-overlap query returns exactly one of: a single matching
candidate (`UNIQUE`), two or more genuinely compatible candidates
(`AMBIGUOUS`, carrying the full candidate set), or none (`NO_DATA`).
Never a forced guess. Regime C resolves every dependency directly via its
binding record, by construction. F10-6's causal-event disambiguation
logic narrows an `AMBIGUOUS` result to `UNIQUE` only if the event names
one of the resolution's own already-computed candidates — it cannot
invent an answer not already present in the observable history.

## Locked scoring algorithm

`src/scoring.py::score_case`. Per dependency, classified into exactly one
of `CORRECT_UNIQUE`, `WRONG_UNIQUE`, `AMBIGUOUS`, `NO_DATA` against ground
truth. Metrics: **Temporal Correctness** (policy AND authority both
`CORRECT_UNIQUE`; scoped identically to the primary experiment — model is
excluded from TC there too), **Unique Reconstruction Rate** (fraction of
the three dependencies `CORRECT_UNIQUE`), **Ambiguity Detection Rate**
(fraction of ground-truth-ambiguous dimensions correctly flagged
`AMBIGUOUS`; undefined/`None` for the non-ambiguous control), **Authorization
Correctness** (`authorized_at_t0` matches ground truth, never guessed
through an unresolved dependency), **False Historical Confidence**
(fraction of the three dependencies that are `WRONG_UNIQUE` — explicitly
and by construction never triggered by `AMBIGUOUS`, per Step 8).
