## Results

| Directory | Config | Description |
|---|---|---|
| `poc_v1/` | `configs/poc.yaml` at commit of the first run | First full run (10 seeds). Controls: E0, E0split, Ealt. Kept unchanged for the record. Its `metrics.csv` has no AltOOD columns. |
| `poc_v2/` | `configs/poc.yaml` | Identical configuration plus the post-hoc control AltOOD (added after reading v1). Same seeds, so shared columns reproduce v1 exactly (checked by comparing the tables). |

Each directory holds `metrics.csv` (per seed, quality, policy, horizon), `quality.csv`, `summary.md`, `summary.json`, `config_used.json`, `run.log`, and `auroc_by_horizon.png`. Interpretation and limits: `topics/bostrom-world-models/notes/results.md`.
| `abl_relu128/` | `configs/abl_relu128.yaml` | Ablation A1: agent theory is a ReLU 128x3 ensemble trained on the same in-distribution data. |
| `abl_poly3/` | `configs/abl_poly3.yaml` | Ablation A2: agent theory is a cubic polynomial regression (different model class). |
| `abl_qwide/` | `configs/abl_qwide.yaml` | Ablation C: agent theory is the baseline architecture trained with actions in [-3, 3]. |
| `abl_analytic/` | `configs/abl_analytic.yaml` | Ablation B: agent theory is the true reference law; actions for the active policy are chosen by a separate learned ensemble. |
| `comparison.md` | | Cross-condition table for quality 3 (generated by `python -m eid.compare`). |

Seed 0 of `poc_v2` and of all four ablations was re-run at full configuration and matched the stored CSVs with 0 mismatches (`scripts/reproduce_check.py`).
| `abl_qindep/` | `configs/abl_qindep.yaml` | Independently trained observer: theory trained on a fresh independent sample of E0 data. |
| `abl_wrelu_qtanh/` | `configs/abl_wrelu_qtanh.yaml` | World model W is ReLU-128x3; theory is the baseline tanh ensemble. |
| `abl_wrelu_qrelu/` | `configs/abl_wrelu_qrelu.yaml` | W and the theory are both ReLU-128x3 (architectures shared). |
| `adaptive_tanh/` | `configs/adaptive_tanh.yaml` | Adaptive observer: 100 adaptation episodes of 10 steps under the test policy, then fine-tuning of the theory on those transitions plus a reference replay, then testing on fresh episodes. |
| `stats.md` | | Seed-paired comparison against the baseline, with Holm-adjusted p-values and practical-significance flags (thresholds fixed in `eid/stats.py`). |
| `figures/observer_comparison.png` | | FPR, TPR and AUROC against horizon for all observers and policies (quality 3). |
| `mechanism_check.txt` | | Output of the exploratory cross-entropy mechanism check. |

All nine experimental conditions had seed 0 re-run at full configuration and matched the stored CSVs with 0 mismatches. ECE and Brier values in `summary.md` are experimenter-side Platt-scaled quantities and are not meaningful where AUROC is below 0.5 (see `notes/results.md`, F6).
