# Compare Approaches

Compare only approaches that already have completed evidence-based reviews.

Before editing:

1. Read `.cursor/context/project.md`.
2. Read each individual review.
3. Confirm that all scores use the same methodology.
4. Identify non-comparable dimensions and scope differences.

Produce a dimension-specific comparison that:

- preserves scope differences,
- distinguishes zero from non-applicability,
- identifies trade-offs,
- relies on evidence already recorded in the reviews,
- avoids unsupported overall rankings,
- identifies recurring reconstruction gaps,
- records where evidence remains insufficient.

Update aggregate matrices only where the underlying reviews support the change.

Finish by listing all comparison limitations.
