# Review Source

Review the source specified by the user against the repository reconstruction
methodology.

Before editing:

1. Read `.cursor/context/project.md`.
2. Read the research charter.
3. Read the reconstruction checklist.
4. Read the review methodology.
5. Read the review template.
6. Confirm that the primary source is available.

Then:

1. Identify the exact source and version.
2. Define the evaluated scope.
3. Summarise the source neutrally.
4. Extract explicit evidence relevant to reconstruction capabilities.
5. Map the evidence to the checklist.
6. Assign justified scores.
7. Record uncertainties and non-applicable criteria.
8. Record what the source does not establish.
9. Create or update one review file only.
10. Do not update aggregate comparison files unless explicitly requested.

Finish by reporting:

- files created or changed,
- principal findings,
- unresolved points,
- confidence in the evaluation,
- validation performed.
