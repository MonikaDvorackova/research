## References

Shared citation corpus for all topics and publications.

| Path | Role |
|---|---|
| `bib/library.bib` | Single BibTeX library |
| `sources/` | Optional source files (license-aware); never the only artifact |

Citation keys: `authorYearShortTitle`. Literature notes in topics must include `cite_key`.
