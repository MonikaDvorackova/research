\section{Discussion and Limitations}
\label{sec:discussion}

WorldConsistMem isolates a measurable Acc--BCR failure mode for memory systems over evolving synthetic worlds. Completed evidence supports dissociation under corruption, symbolic retrieval, Qwen Option~A, and labelled robustness checks.

\subsection{Threats to validity}
\label{sec:threats}

\paragraph{Leakage / shortcuts.} LLM evidence packs assert no gold/constraint fields in prompts. Shortcut baselines (Section~\ref{sec:robustness}) show that answer marginals can yield Acc$>$0 with BCR~$=$~0; gold recovers BCR~$=$~1. Symbolic readers use structured match over retrieved observations, not free-form generation.

\paragraph{Generator dependence.} Worlds are templated; seed sweeps show limited diversity for B3 under wpt$=$6. Relation-density overrides preserve gaps but do not strongly change event counts in the tested medium regime. Distractors are a null factor for symbolic B3/B4. Results characterize this generator, not all synthetic worlds.

\paragraph{Model dependence.} Option~A uses one local 3B Qwen reader with high abstention. Stronger readers were not completed here. Low Acc limits how far Qwen tables speak beyond Acc$\neq$consistency and BCR-floor/CSR questions.

\paragraph{Synthetic scope / sample size.} Ecological validity is not claimed. Full symbolic $N{=}102$ worlds; Qwen H4 uses 18 worlds; labelled robustness uses smaller protocols and must not be read as Option~A.

\paragraph{Fairness.} Compact-flat saturation and H0 metadata taxation bound matched-budget interpretation (Appendix~\ref{app:fairness}).

\subsection{When to use BCR vs CSR}
BCR is the strict rate for fully coherent bundles. When BCR floors, report CSR, violation multiplicity, and family hits; do not replace BCR with a favorable PConsAcc cell.
