\section{Introduction}
\label{sec:intro}

Long-term memory systems answer questions about evolving worlds: what is true now, what was true earlier, how transitions occurred, and which evidence supports those claims. Most evaluations score these questions \emph{one at a time} via answer accuracy, retrieval fitness, conflict handling, or lifecycle metrics~\citep{wu2025longMemEval,wu2026longMemEvalV2,hu2025memoryAgentBench,tao2026memConflict,xie2026dynamicMem,wang2026evoMemBench,hu2026everMemBench,liu2026worldMemArena}. Per-query Acc can look strong while the answer set still fails as one coherent world history.

\paragraph{Central failure mode.} A system may correctly name the current CEO and the previous CEO, yet assert an impossible transition between them (Figure~\ref{fig:inconsistency}). Each answer can match gold under exact match; the bundle is nevertheless inconsistent. Ordinary Acc does not detect this joint failure.

\paragraph{Research question.} Under evolving synthetic worlds with dependent query bundles and machine-checkable cross-query constraints, when do systems that achieve high per-query Acc still fail joint consistency, and which partial diagnostics remain informative when strict consistency floors?

We introduce \textbf{WorldConsistMem} as a \emph{controlled diagnostic instrument}: dependent bundles grounded in one deterministic gold history; constraints $\mathcal{C}$ derived automatically from that history; consistency scored by predicates $\Phi$ over the predicted answer set from a reader conditioned on memory state $M_T$, without access to memory internals. \textbf{BCR} is the fraction of bundles with $\Phi=1$; $\Gapq=\Acc-\BCR$ measures the Acc--consistency gap; \textbf{CSR} provides partial resolution when BCR floors.

\paragraph{Contributions.}
\begin{enumerate}[leftmargin=*,itemsep=1pt]
\item Formal evaluation object separating per-query Acc from joint world-history consistency $\Phi$.
\item WorldConsistMem benchmark (102 worlds, 1{,}088 bundles, 7{,}140 queries; seed-100 freeze).
\item Metrics BCR, CSR, ConsAcc, and $\Gapq$, with world-level uncertainty where released.
\item Empirical characterization: corruption and symbolic dissociation; Qwen BCR floor with CSR residual; labelled robustness checks (seeds, density, distractors, shortcut baselines). Architecture superiority is \textbf{not} claimed.
\end{enumerate}

Adjacent logical-consistency work already separates Acc from global coherence on multi-query case files~\citep{salla2026crossQueryContradictions,chaudhry2026logicVault}. Existing LTM benchmarks emphasize long-horizon Acc. Our residual is their intersection: persistent memory evaluation over evolving multi-entity worlds with world-history-derived constraints.
