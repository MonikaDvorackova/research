# Non-memory scientific-object search

**Programme pivot:** Publication 03 is **not** a memory paper. Hierarchical LTKM is experimental infrastructure only.

**Required question:** What ML phenomenon cannot even be studied without persistent long-term interaction, yet whose scientific contribution is fundamentally **not** about memory?

**Immediate reject if fundamentally about:** retrieval, storage, allocation, forgetting, consolidation, memory architecture, memory benchmarks, context length, RAG, memory policy.

**Final recommendation:**  
# **NO VIABLE NON-MEMORY SCIENTIFIC OBJECT FOUND USING THE CURRENT PLATFORM**

---

## Why the search fails (summary)

1. **Strong long-horizon non-memory phenomena are occupied (2024–2026):** performative prediction; multi-turn sycophancy / Truth Decay / SYCON; BeliefShift / delayed verification; latent preference discovery; long-horizon planning diagnosis; agent-log causal ID.
2. **Many “need history” ideas are memory papers in disguise** (spurious correlations *in agentic memory*; trajectory neglect with memory write/retrieve; etc.).
3. **Platform mismatch:** Surviving non-memory ideas need *some* multi-session log or long MDP, not specifically this hierarchical LTKM laboratory. Using it would look opportunistic without strengthening the claim.
4. **Hostile filter:** Do not force a recommendation to keep Pub-03 alive.

## Candidates (≤10)

### N1 — Performative prediction in multi-session agent–user loops

1. **Object:** Convergence / stability of predictions when agent outputs reshape future user/environment distributions across sessions.  
2. **Why persistent state experimentally:** Need multi-session trajectories where early predictions alter later covariates/outcomes; lab logs interaction + induced distribution.  
3. **Why not memory:** Claim is performative ML / decision-dependent data, not storage/retrieval.  
4. **Closest literature:** Perdomo et al.; NeurIPS 2024–2025 performative prediction (DRPO, Affine Risk Minimizers, online stability); surveys 2026; dialogue future-feedback / IEvoAgent adjacent.  
5. **Novelty:** **OCCUPIED** (theory dense); LLM-agent instantiation at best incremental application.  
6. **Falsify:** If multi-session LLM loops show no performative shift vs static user simulator → no phenomenon.  
7. **ICLR type:** Learning dynamics / optimization (if novel); else evaluation.  
8. **Risk:** “Apply performative prediction to dialogue.”

**Survive?** No.
