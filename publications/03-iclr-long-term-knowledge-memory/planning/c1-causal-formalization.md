# C1 causal formalization

## 1. Minimal memory decision process

At each write opportunity \(t\):

| Symbol | Meaning |
|---|---|
| \(S_t\) | Environment / task state (may include latent query type \(U\) realized later) |
| \(O_t\) | Observation available to the agent |
| \(X_t\) | Candidate memory item |
| \(W_t\in\{0,1\}\) | Write action (skip / store) |
| \(M_t\) | Memory store after applying \(W_t\) (capacity \(K\); eviction if full) |
| \(H_t\) | History / information set used by policies (subset of \(\{O_{\le t},X_{\le t},W_{<t},M_{t-1},\ldots\}\)) |
| \(Q_{t+H}\) | Future query / utility event at lag \(H\) |
| \(R_{t:t+H}\) | Downstream return from \(t\) through the utility event (and any intermediate rewards) |
| \(\mu(W_t\mid H_t)\) | Behavior (logging) write policy |
| \(\pi(W_t\mid H_t)\) | Target write policy |

**Potential outcomes.** Let \(R(w)\) be the return that would be realized if \(W_t\) were set to \(w\in\{0,1\}\), with other mechanisms held as specified by an intervention regime (see interference caveat below).

**Counterfactual write value**

\[
V_t^{\mathrm{write}}
=
\mathbb{E}\big[R(W_t{=}1)-R(W_t{=}0)\mid H_t\big].
\]

**Observational identifiability (claim A).**  
Is \(V_t^{\mathrm{write}}\) a functional of the observational law \(P_\mu\) of trajectories generated by \(\mu\), without intervening on \(W_t\)?

## 2. Assumptions for identification (standard toolkit)

| Assumption | Role | Likely status in agent memory |
|---|---|---|
| Consistency | \(R=R(W_t)\) when \(W_t\) is the realized write | Fragile under capacity: realized return depends on **other** writes |
| Positivity | \(0<\mu(1\mid H_t)<1\) a.s. on support of interest | Often violated: near-deterministic managers; GRPO groups ≠ positivity for OPE |
| No unobserved confounding / sequential ignorability | \(R(w)\perp W_t\mid H_t\) | Violated if latent future query type \(U\), tool noise, or LLM stochasticity affect both write and return and are not in \(H_t\) |
| Stable unit treatment (no interference) | \(R_i(w)\) independent of other units’ writes | **Structurally violated**: capacity-\(K\) eviction couples writes |
| Known logging propensities | IPS/DR need \(\mu\) | Often unknown for LLM managers; synthetic logging can know \(\mu\) |
| Stable dynamics | \(P(O,M,Q\mid\cdot)\) fixed | Non-stationary agents / curriculum shift violate |
| Sufficient observability of \(H_t\) | Conditioning set includes all common causes | Compressed memory agents routinely omit causes |

**Memory-specific structural facts (not free gifts from CI textbooks):**

1. **Write → future observation channel:** \(W_t\) changes \(M_t\), which changes retrieval and thus future \(O_{>t}\) and actions — treatment affects mediators and future covariates.
2. **Capacity interference:** Individual \(R(W_t{=}1)\) is ill-specified without a regime for \(W_{t'}\), \(t'\neq t\).
3. **Delayed query uncertainty:** Utility of \(X_t\) may depend on \(U\sim p(U)\) revealed only at \(t+H\).
4. **Endogenous policy feedback:** Learned \(\pi\) trained on biased values changes future \(M\) distribution, altering later identification/estimation problems.

## 3. Three claims (do not conflate)

### A. Statistical identifiability

Whether \(V_t^{\mathrm{write}}\) is determined by \(P_\mu\).

- Without positivity → generally **non-identifiable** (standard).
- With unobserved confounding → generally **non-identifiable** (standard).
- With interference → **individual** \(V_t^{\mathrm{write}}\) may be **ill-defined**; only **joint** interventions \(W_{t:t+L}\) are well-defined (standard interference / SUTVA, instantiated by capacity).

### B. Finite-sample estimation

Even when identified, estimators may have huge variance (rare writes; long \(H\)) or optimization bias.  
TCM’s env-clock vs op-clock result is primarily **B** (credit signal decays through silence), not Pearl **A**.  
Memory-R2’s local rerolls reduce **comparison unfairness / estimation contamination**, not a proof of non-identifiability.

### C. Policy-learning consequence

Whether errors in estimating write value cause systematically wrong retention (e.g., drop delayed-critical items).  
TCM and Memory-R2 ablations speak to **C** under their estimators; neither reports C1’s observational-vs-interventional \(\rho\) / 15pp delayed-critical retention protocol against oracle \(V^{\mathrm{write}}\).

**Publishable C1 would need A or B → C with a memory-specific mechanism.**  
Relabeling “no positivity ⇒ non-ID” as a memory paper fails the hostile filter.

## 4. Candidate formal statements

### What is *not* acceptable as the main theorem

- “If \(\mu(w\mid H)=0\) for some \(w\), write value is non-identifiable.” → **standard**
- “If \(U\notin H_t\) confounds \(W\) and \(R\), non-identifiable.” → **standard**
- “Trajectory GRPO is unfair when memories diverge.” → **Memory-R2 already**

### Strongest nontrivial proposition available in a minimal tabular setting

**Proposition (interference / ill-defined unit write value under capacity).**  
Consider capacity \(K=1\), two write opportunities \(t_1<t_2\), items \(X_{t_1}\) (delayed-critical for query at \(t_1+H\)) and \(X_{t_2}\) (distractor with immediate spurious correlation with return under \(\mu\)). Eviction is last-write-wins. Then:

1. The map \(w\mapsto R(W_{t_1}=w)\) is **not** well-defined without specifying \(W_{t_2}\) (SUTVA failure).
2. Define the **ceteris-paribus** advantage by intervening only at \(t_1\) with \(W_{t_2}\) fixed by a frozen regime \(\nu\). Define the **naive observational attribution** \(\widehat{A}_{\mathrm{naive}}(X_{t_1})=\mathbb{E}_\mu[R\mid W_{t_1}=1,H_{t_1}]-\mathbb{E}_\mu[R\mid W_{t_1}=0,H_{t_1}]\).
3. There exist parameters \((H,p_{\mathrm{query}},\mu)\) such that \(\mathrm{sign}(\widehat{A}_{\mathrm{naive}})=-\mathrm{sign}(V^{\mathrm{cp}}_{t_1})\) — naive observational contrast **sign-flips** relative to the ceteris-paribus interventional write advantage — because \(\mu\) correlates distractor writes with returns via capacity occupancy.

**Status:** Provable in a tiny tabular MDP (yes).  
**Novelty risk:** This is **interference + confounding through a capacity mediator** — still largely **standard causal inference with a memory costume**. AC-hostile reading: not ICLR-new theory.

### Alternative proposition closer to Memory-R2 (already occupied as insight)

Under diverging endogenous \(M\), group-normalized trajectory advantages are not unbiased for session-level write advantages — **Memory-R2’s reason for local rerolls**. Formalizing that as an OPE bias identity is incremental to Memory-R2.

### Alternative closer to TCM (already occupied)

Env-clock eligibility loses write credit through operation-free delay \(B\) while op-clock does not — **TCM Theorem/Appendix**. Do not restate.

### Honest conclusion on formal content

**No strong memory-native theorem** was found that is simultaneously:

- beyond standard CI assumptions,
- not already the operational insight of Memory-R2 / HiMPO / TCM,
- and sufficient as an ICLR theory spine for Pub-03.

The interference sign-flip construction is the best tabular statement, but it does **not** clear the hostile “standard CI applied to memory” bar as a standalone contribution.
